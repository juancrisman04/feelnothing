# Feel Nothing Web

Sitio estatico con servidor Node para servir archivos locales y registrar pedidos.

## Comandos

```bash
npm start
```

El servidor levanta la web en `http://localhost:3000` por defecto. Se puede cambiar el puerto con la variable `PORT`.

## Checkout, Supabase y correos

El pago envia el pedido a `/api/orders`. El servidor guarda una copia local en `data/orders.json`, registra el pedido en Supabase si estan configuradas las variables, manda un correo al dueno de la tienda y otro de gracias al cliente usando Resend.

Variables necesarias en `.env`:

```bash
OWNER_EMAIL=juancrisman04@gmail.com
RESEND_API_KEY=tu_api_key_de_resend
FROM_EMAIL=Feel Nothing <compras@tudominio.com>
SUPABASE_URL=https://tu-proyecto.supabase.co
SUPABASE_SERVICE_ROLE_KEY=tu_service_role_key
SUPABASE_ORDERS_TABLE=orders
```

Tabla sugerida en Supabase:

```sql
create table if not exists orders (
  id bigint generated by default as identity primary key,
  order_id text not null unique,
  created_at timestamptz not null,
  customer jsonb not null,
  items jsonb not null,
  shipping numeric not null,
  total numeric not null,
  source text not null default 'web-checkout'
);
```

Usa la `service_role key` solo en el servidor, nunca en archivos del navegador.

## Estructura

- `index.html`: home.
- `remeras.html`, `pantalones.html`, `bermudas.html`, `buzos.html`: catalogos.
- `*-html` de producto: paginas de detalle.
- `checkout.html` y `payment.html`: flujo de compra.
- `css/main.css`: estilos de la web.
- `js/`: comportamiento de catalogo, carrito, checkout y detalle de producto.
- `img/`, `imgremeras/`, `imgpantalones/`: imagenes del sitio.
